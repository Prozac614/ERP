# 商品库存数据导出功能说明

## 功能概述

新增了商品库存数据导出功能，用户可以将指定时间范围内的所有商品库存数据导出为Excel文件。

## 功能特点

### ✅ **支持的导出内容**
- 商品编码
- 商品名称  
- 规格型号
- 单位
- 本期结存
- 上期结存
- 本期出库
- 上期出库
- 本期入库
- 上期入库

### ✅ **支持的筛选条件**
- 商品信息筛选（商品名称、编码等）
- 时间范围筛选
- 导出所有符合条件的数据（不受分页限制）

### ✅ **文件格式**
- Excel格式（.xlsx）
- 自动生成带时间戳的文件名
- 表头样式美化
- 自动调整列宽

## 使用方法

### 1. **访问功能**
- 登录系统后进入首页
- 在商品库存统计表格上方可以看到"导出库存"按钮

### 2. **设置筛选条件**
- 可以在查询区域设置筛选条件：
  - 商品信息：输入商品名称、编码等关键词
  - 开始时间：设置查询的开始时间
  - 结束时间：设置查询的结束时间

### 3. **执行导出**
1. 点击"导出库存"按钮
2. 系统会弹出确认对话框
3. 点击"确定"开始导出
4. 系统显示"正在导出数据，请稍候..."提示
5. 导出完成后自动下载Excel文件

### 4. **文件说明**
- 文件名格式：`商品库存数据_YYYYMMDD_HHMMSS.xlsx`
- 例如：`商品库存数据_20241219_143025.xlsx`

## 技术实现

### 后端实现
- **Controller**: `DepotItemController.exportMaterialStock()`
- **Service**: `DepotItemOptimizedService.exportMaterialStockToExcel()`
- **技术栈**: Apache POI (XSSFWorkbook)

### 前端实现
- **组件**: `IndexChart.vue`
- **方法**: `handleExport()` 和 `exportData()`
- **技术**: Fetch API + Blob下载

### API接口
```
GET /depotItem/exportMaterialStock
参数：
- currentPage: 页码（导出时固定为1）
- pageSize: 每页数量（导出时设为最大值）
- materialParam: 商品筛选参数（可选）
- beginTime: 开始时间（可选）
- endTime: 结束时间（可选）
```

## 注意事项

### ⚠️ **性能考虑**
- 导出大量数据时可能需要较长时间
- 建议在数据量较大时使用筛选条件缩小范围
- 系统会显示加载提示，请耐心等待

### ⚠️ **权限要求**
- 需要登录系统
- 需要有库存查询权限
- 导出功能继承查询权限

### ⚠️ **浏览器兼容性**
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 使用Fetch API和Blob，IE浏览器可能不支持

## 故障排除

### 问题1：导出按钮点击无反应
**解决方案**：
- 检查网络连接
- 确认登录状态
- 刷新页面重试

### 问题2：导出失败提示
**解决方案**：
- 检查筛选条件是否合理
- 确认数据权限
- 联系系统管理员

### 问题3：文件下载失败
**解决方案**：
- 检查浏览器下载设置
- 确认磁盘空间充足
- 尝试更换浏览器
