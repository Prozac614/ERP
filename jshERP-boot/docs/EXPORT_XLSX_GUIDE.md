# 商品库存数据XLSX导出功能

## 功能概述

已升级导出功能，现在支持导出XLSX格式的Excel文件，并包含完整的单日出库数据。

## 🎯 **新功能特点**

### ✅ **XLSX格式导出**
- 真正的Excel格式（.xlsx）
- 支持复杂的表格结构
- 自动调整列宽
- 更好的兼容性

### ✅ **完整的数据导出**
**基础数据：**
- 商品编码
- 商品名称
- 本期结存
- 上期结存
- 本期出库
- 上期出库

**单日出库数据：**
- 动态生成每日出库列
- 按日期排序显示
- 显示每个商品每天的出库数量
- 支持任意时间范围的单日数据

### ✅ **智能数据处理**
- 自动检测可用的单日出库数据
- 动态生成表头
- 按日期排序显示
- 空数据显示为0

## 📋 **导出内容示例**

```
商品编码 | 商品名称 | 本期结存 | 上期结存 | 本期出库 | 上期出库 | 2024-12-01出库 | 2024-12-02出库 | ...
ABC001  | 商品A   | 100     | 120     | 50      | 30      | 5            | 8            | ...
ABC002  | 商品B   | 80      | 90      | 20      | 15      | 3            | 2            | ...
```

## 🚀 **使用方法**

### 1. **安装依赖**
首次使用需要安装XLSX库：
```bash
cd jshERP-web
npm install
```

### 2. **导出步骤**
1. **查看数据**：在首页查看商品库存统计表格
2. **设置筛选**：可以设置时间范围和商品筛选条件
3. **点击导出**：点击"导出库存"按钮
4. **确认导出**：在弹出对话框中点击"确定"
5. **自动下载**：浏览器自动下载XLSX文件

### 3. **文件说明**
- **文件格式**：Excel (.xlsx)
- **文件名**：商品库存数据_YYYYMMDD_HHMMSS.xlsx
- **工作表名**：商品库存数据

## 💡 **技术实现**

### 前端实现
- **库**：xlsx (^0.18.5)
- **导入方式**：动态导入，按需加载
- **数据源**：直接使用前端表格数据和单日出库数据
- **格式**：XLSX工作簿格式

### 数据结构
```javascript
// 基础数据来源
dataSource: [
  {
    barCode: '商品编码',
    materialName: '商品名称',
    currentPeriodStock: 100,
    previousPeriodStock: 120,
    currentPeriodOut: 50,
    previousPeriodOut: 30,
    materialId: 'material_id'
  }
]

// 单日出库数据来源
dailyOutData: {
  '2024-12-01': {
    'material_id_1': 5,
    'material_id_2': 3
  },
  '2024-12-02': {
    'material_id_1': 8,
    'material_id_2': 2
  }

```

## ⚠️ **注意事项**

### 性能考虑
- 大量数据导出可能需要较长时间
- 单日出库数据越多，文件越大
- 建议合理设置时间范围

### 浏览器兼容性
- 支持现代浏览器
- 需要支持ES6动态导入
- 需要支持Blob和URL.createObjectURL

### 数据准确性
- 导出的是当前前端显示的数据
- 确保数据已完全加载后再导出
- 单日出库数据依赖于时间范围设置

## 🔧 **故障排除**

### 问题1：导出按钮无反应
**解决方案**：
- 检查是否有数据
- 确认网络连接正常
- 刷新页面重试

### 问题2：XLSX库加载失败
**解决方案**：
- 检查网络连接
- 重新安装依赖：`npm install`
- 清除浏览器缓存

### 问题3：导出文件打不开
**解决方案**：
- 确认使用Excel 2007或更高版本
- 尝试使用WPS Office打开
- 检查文件是否完整下载

### 问题4：缺少单日出库数据
**解决方案**：
- 确认已设置时间范围
- 检查该时间范围内是否有出库记录
- 确认数据已完全加载
