# 库存图表组件使用说明

## 功能概述

`StockChartModal` 组件用于展示商品的库存变化趋势和出库数据，采用双纵坐标图表设计：
- 左侧纵坐标：库存量（折线图）
- 右侧纵坐标：出库量（柱状图）
- 横坐标：日期范围

## 使用方法

### 1. 在首页表格中点击"查看图表"按钮
- 确保已设置统计日期范围
- 点击任意商品行的"查看图表"按钮

### 2. 图表功能
- **数据缩放**：支持滑块和鼠标滚轮缩放
- **数据导出**：点击"导出图表"按钮保存为PNG图片
- **数据刷新**：点击"刷新数据"按钮重新加载数据
- **工具栏**：支持数据缩放、还原、保存图片等操作

### 3. 图表特性
- **双纵坐标**：库存量和出库量分别使用不同的纵坐标
- **低库存警戒线**：红色虚线标识低库存警戒线（20件）
- **智能补货模拟**：基于出库量模拟合理的补货逻辑
- **响应式设计**：自适应不同屏幕尺寸

## 技术实现

### 数据来源
- 使用现有的 `/depotItem/getDailyOutStock` API获取出库数据
- 基于商品的期间库存信息计算初始库存
- 通过出库数据反推库存变化趋势

### 性能优化
- 日期范围限制（最大365天）
- 请求超时保护（30秒）
- 错误处理和重试机制
- 内存清理和组件销毁处理

### 依赖项
- ECharts 5.4.3：图表渲染
- Moment.js 2.29.4：日期处理
- Ant Design Vue：UI组件

## 故障排除

### 常见问题
1. **图表不显示**：检查是否设置了统计日期范围
2. **数据为空**：确认商品在指定时间范围内有出库记录
3. **加载失败**：检查网络连接和后端API状态

### 调试信息
组件会在浏览器控制台输出详细的调试信息，包括：
- 请求参数
- API响应数据
- 数据转换过程
- 错误信息
